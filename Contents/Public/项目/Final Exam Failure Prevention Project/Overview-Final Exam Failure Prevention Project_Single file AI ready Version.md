- 民航机票节假日与非节假日的价格案例分析题
	国内某民营航空公司主营国内客运航线，飞行成本固定，单趟航班飞行固定成本为45000元，空载飞行同样需要承担全额固定成本。该航空公司为提高航班客座率、最大化企业利润，针对同一航线、同一舱位的机票实行差别化定价，严格采用多种差异化售票方案，具体经营定价情况如下：
	1. 客户身份差别定价：航空公司对学生、老人、残疾人推出专属优惠机票，凭有效证件可享受票价7.5折优惠；普通成年旅客无身份优惠，执行标准票价。该航空公司可通过证件精准区分消费人群，两类人群价格敏感度差异明显。
	2. 购票时间差别定价：航班起飞前30天提前购票，机票折扣低至4折；起飞前7天购票，机票折扣为7折；起飞前24小时内临时购票，机票无折扣、全额售卖。提前购票旅客多为旅游、探亲人群，出行弹性大；临时购票多为商务刚需人群，价格敏感度极低。
	3. 购票数量套餐定价：航空公司推出单人单程票、双人往返套票、家庭年卡套餐。单人单次出行无优惠，双人往返套票总价直降200元，家庭年卡可享受10次出行8折优惠，消费者可自主选择购票数量与套餐类型。 补充行业现状：该航空公司航线具有排他性，同航线竞争对手较少；机票无法二次转售，实名制购票杜绝低价票倒卖行为；航班空座无法储存，一旦航班起飞，空座成本全部亏损。节假日航班满座，非节假日航班空置率高达40%。 请根据上述内容，回答以下几个问题：
	4. 结合价格歧视分类知识点，判断案例中三种定价方式分别属于哪一类价格歧视，并写出三类价格歧视的定义。（30分）
	5. 结合案例内容，分析该航空公司能够成功实行价格歧视的必备条件。（25分）

- 基于价格歧视理论的航空公司案例分析题
	国内某主流民航航空公司主营国内客运航线，主打旅游、探亲出行航线，覆盖国内热门旅游城市及返乡刚需航线。该航空公司机票定价随节假日呈现明显差异化波动，2025年出行数据及票价统计如下：
	1. 非节假日（工作日、普通周末）：航线机票原价800元/张，为提升客座率，航空公司长期推出折扣机票，平均折扣票价为400元/张，此阶段日均机票售出量为2000张；非节假日出行人群多为商务出差、错峰旅游人群，出行可灵活调整出行时间。
	2. 法定节假日（五一、国庆、春节）：航空公司取消全部折扣优惠，机票恢复原价800元/张，部分热门航线票价上浮20%，达到960元/张；即便票价大幅上涨，节假日期间日均机票售出量仍达到4500张。节假日出行人群以家庭探亲、休闲旅游为主，出行时间集中，极少人群愿意更改节假日出行计划。
	3. 补充行业现状：每年节假日期间，即便民航部门增加航班、投放更多运力，机票仍常出现售罄、一票难求的情况；而非节假日大量航班空置，客座率不足50%，航空公司为减少空座亏损，持续低价促销。 请结合上述材料，分析以下问题：

	5. 运用弹性理论，分析节假日机票价格大幅上涨、销量不降反升的核心原因。（30分）
	6. 结合需求价格弹性影响因素，简述机票行业弹性系数变化的主要影响因素。（20分）
	7. 基于弹性知识点，为该航空公司优化机票定价策略提出4条合理化建议。（35分）
