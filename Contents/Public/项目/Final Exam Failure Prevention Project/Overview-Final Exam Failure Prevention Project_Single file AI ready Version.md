## 复习总目标
只求**通过考试**，不求对知识点的完全掌握。
仅建立基本可用于应付考试的知识体系。
复习所产生的输出应该可被持久化而为后续进一步（往考研方向）发展做好准备
## 可用资料
历次作业，期末复习题（期末考试基于这套题目，仅高数适用），来自千问录音纪要功能的一部分课程录音，课本，B站网课（高数）/慕课视频（毛概，财政学，微观经济学）
*作业题目/复习题（高数）为主（生成待复习对象列表），课程录音为辅（在执行列表时进行补充），课本和视频作为后备资料*
*高数的作业题目作为巩固用*
### 高等数学C
#### 复习思路
1. 以如下清单为主体，进行初步学习后通过平时作业巩固，并利用LLM、网课（主要）和课本（次要）解疑。

#### 来自期末复习题的知识点清单
##### 模块一：定积分

- [ ] **基本概念与性质：**
    - [x] 定积分的性质（如线性性质、区间可加性等）
    - [x] 积分中值定理
    - [x] 定积分的几何意义（利用几何图形求面积）
- [ ] **计算方法：**
    - [x] 定积分的凑微分法（换元积分法）
    - [x] 定积分的分部积分法
    - [x] 利用奇偶性、点火公式（Wallis公式）求定积分的值
- [ ] **变限积分与广义积分：**
    - [x] 变限积分函数的求导
    - [ ] 无穷限广义积分的敛散性判定
    - [ ] 无界函数广义积分的敛散性判定
- [ ] **综合应用：**
    - [ ] 定积分的几何应用：求平面图形的面积
    - [ ] 定积分的几何应用：求旋转体的体积

##### 模块二：多元函数微积分

- [x] **极限与连续：**
    - [x] 多元函数的极限计算
- [ ] **偏导数与全微分：**
    - [ ] 多元隐函数的偏导数求法
    - [x] 抽象函数的偏导数（复合函数求导法则）
    - [ ] 二元函数的全微分计算

##### 模块三：二重积分
